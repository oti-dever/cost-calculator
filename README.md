# Cost Calculator (电商订单成本计算器)

这是一个用于处理电商订单 Excel 文件的 Python 工具，能够自动根据订单备注计算各类成本，并生成包含详细成本明细和店铺统计的新 Excel 文件。

## 功能特点

*   **自动成本计算**：
    *   **统一 Excel 配置**：基础商品、枕芯、义乳/义臀、硅胶/电动价格统一由 `成本配置.xlsx` 管理。
    *   **基础成本**：通过关键词、尺寸和材质匹配自动计算商品基础成本。
    *   **代发成本**：能识别 "枕芯"、"yr"/"义乳"、"yt"/"义臀" 等关键词，并自动计算代发附加费。
    *   **义乳/义臀、枕芯、硅胶/电动**：按配置工作表中的关键词和价格计算。
*   **智能店铺统计**：
    *   自动从 "商家/店铺" 列提取并规范化店铺名称。
    *   生成独立的 "店铺统计" Sheet，按店铺汇总各项成本（支持 Excel 公式动态更新）。
*   **特殊处理**：
    *   支持多商品订单合并计算（通过 `。` 分割）。
    *   自动识别数量（通过逗号统计）。
    *   海外订单自动识别（"发海外"关键词），并预留空位供手动填写。
    *   错误检测与标记。
*   **未匹配记录追踪**：
  *   成本明细中新增 `无法匹配原因说明` 列，精确说明缺少的商品类型、尺寸、材质或完整规格。
  *   每个 Excel 都会输出未匹配明细。
  *   明细包含：`行号`、`订单编号`（仅读取“订单编号”列）、`未匹配原因`、`备注摘要`。
  *   支持快速定位并修改源数据后重跑。
*   **Textual 日志详情视图**：
  *   在界面中可打开“查看日志详情”弹窗。
  *   按文件分组展示（一个文件一个表格），便于批处理排查。
*   **输出格式**：
    *   保留原始数据，新增成本明细列。
    *   生成带有公式的统计表，方便后续手动调整数据后自动重算。

## 环境要求

*   Python 3.10+
*   `uv`（推荐用于环境与依赖管理）
*   依赖库：`pandas`, `openpyxl`
*   界面依赖：`textual`（终端图形界面）
*   打包稳定性建议：`rich==13.9.4`（已在 `requirements.txt` 固定）

## 安装

1.  克隆或下载本项目。
2.  使用 `uv` 创建并激活虚拟环境。
3.  使用 `uv` 同步依赖。

```bash
uv venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
uv pip install -r requirements.txt
```

> 说明：本项目当前默认使用 Textual 终端界面；业务计算逻辑保持不变。

## 使用方法

### 方式一：命令行运行

```bash
uv run python cost_calculator.py
```

或使用脚本入口：

```bash
uv run cost-calculator
```

启动后会进入 Textual 界面，在输入框填写文件或目录路径进行处理。

### 方式二：Textual 界面处理

先启动程序（见“方式一”任一命令），然后按以下步骤操作：

1. 在 **输入目标（文件/文件夹）** 中添加待处理路径。
    - 点击 **选择文件**，使用系统文件选择窗口选择 `.xlsx` 或 `.xls` 文件。
    - 点击 **选择文件夹**，使用系统文件夹选择窗口选择包含 Excel 文件的文件夹。
    - 每次成功选择都会覆盖输入框中的旧内容；取消选择时保持原内容不变。
    - 也可以直接在输入框中填写路径。
    - 单文件示例：`test_excel\\抖音2.1-2.11.xlsx`
    - 目录示例：`test_excel`
    - 多目标示例：`"a.xlsx" "b.xlsx"`
2. 如需调整价格，点击 **打开配置**，在 Excel 中新增或修改数据，然后保存并关闭。
3. （可选）在 **输出目录（可留空）** 中填写结果输出目录。
    - 留空：输出到源文件同目录
4. （可选）勾选 **覆盖同名文件**。
5. 点击 **开始处理**；程序会在每个批次开始前重新加载配置。
6. 在界面下方查看结果：
    - 结果摘要表（状态、输入、输出、匹配、说明）
    - 结果详情面板（选中一行查看完整路径与完整说明）
    - 日志区实时输出处理过程
7. 如需查看未匹配明细，点击 **查看日志详情**：
    - 按文件分组展示（一个文件一个表格）
    - 表格列：`行号`、`订单编号`、`原因`、`备注`

界面支持：

* 输入单个文件或目录
* 批量输入多个目标（空格分隔，带空格路径请使用引号）
* 自定义输出目录
* 同名文件覆盖开关
* 一键打开 Excel 成本配置
* 结果表格与日志面板实时查看
* 结果摘要表 + 结果详情面板（解决长路径/长信息截断问题）
* 日志详情弹窗（按文件分组表格展示未匹配明细）

### 方式三：打包为 EXE (Windows)

先运行构建脚本：

```bash
uv run cmd /c build.bat
```

或先激活环境后执行：

```bash
build.bat
```

构建成功后会生成：`dist/CostCalculator.exe`。

构建完成后会自动复制测试数据目录到：`dist/test_excel`（若源目录存在），便于直接验收测试。

如果已经使用 PyInstaller 打包生成了 exe 文件，双击后会进入 Textual 界面。

当前构建脚本默认生成 **单文件 EXE**（`--onefile`），并将 `成本配置模板.xlsx` 内嵌到可执行文件中。

首次启动时，程序会在 EXE 同目录自动创建可编辑的 `成本配置.xlsx`。之后只读取这份外部配置，不会覆盖使用者的修改。因此正式发布目录至少包含：

* `CostCalculator.exe`
* 首次运行后自动出现的 `成本配置.xlsx`

## Excel 配置说明

点击界面的 **打开配置** 可直接编辑 `成本配置.xlsx`。修改后必须保存并关闭 Excel，再点击“开始处理”。程序会在每个批次开始前重新读取并严格校验配置；文件仍被占用或数据非法时，本批次不会生成任何输出。

配置工作簿包含：

| 工作表 | 用途 | 新增方式 |
| --- | --- | --- |
| `使用说明` | 录入规范和注意事项 | 不参与解析 |
| `全局参数` | 配置版本、代发单价 | 修改“值”列 |
| `基础商品类别` | 类别名称与匹配优先级 | 新增一行 |
| `基础商品关键词` | 类别可识别的备注关键词 | 新增一行 |
| `基础商品价格` | 类别/材质为行，尺寸为列的价格矩阵 | 新增材质行或尺寸列 |
| `枕芯价格` | 尺寸/材质为行，六种枕芯类型为列的价格矩阵 | 新增尺寸/材质行 |
| `义乳义臀价格` | 完整备注关键词、单价 | 新增一行 |
| `其他成本` | 硅胶、电动等关键词和单价 | 新增一行 |

配置规则：

* 不得修改工作表名称和表头。
* 全空行会被忽略；类别、材质、尺寸等固定字段不得留空。
* 两张价格矩阵中，空白单价表示该组合未配置；每行至少要有一个价格。
* 数据区域不得使用合并单元格或公式。
* 单价必须是非负数字。
* 尺寸必须使用 `数字*数字`，例如 `50*160`。
* 重复关键词、重复价格键、无效类别引用会显示工作表名和 Excel 行号。
* 当前正式材质关键词为 `SSS`，不是 `SAS`。
* 不含“羽绒棉”的枕芯关键词代表 PP 棉枕芯。
* 起毛套不计费，不在配置中维护。

旧的四份 JSON 配置已停止支持，程序只读取 `成本配置.xlsx`。

## 输入输出规范

*   **输入文件**：必须包含 **"卖家备注"** 和 **"商家/店铺"** 两列。支持 `.xlsx` 和 `.xls` 格式。
*   **输出文件**：将在原文件目录下生成 `{原文件名}-已处理.xlsx`。
*   **原因说明**：成功行留空；失败行说明未匹配的类型、尺寸、材质或完整规格；海外行提示人工核对。

## 注意事项

*   对于 `.xls` 格式的旧版 Excel 文件，处理后的样式可能无法完全保留，建议使用 `.xlsx`。
*   海外订单（备注包含 "发海外"）的成本列会被置空，需要人工核对填写。
*   配置工作簿被 Excel 打开时不会处理订单；请先保存并关闭配置。
